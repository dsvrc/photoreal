EXTRA SEEDS FOR THE VARIANCE ANALYSIS, STEP 1 ONLY (train on RLW104, replay PXB184, test on PXB184 RLW104)
Methods: gcr mir csrel tmr

Run from the repo root in a2p_env:
cd /scratch/ee/staff/kaizer1.cstaff/3d_new/photoreal

What a seed is:
- seed 0 is the run you already have: buffer --seed 0, train --seed 10 (the defaults), in runs/ and cl_data/buffers/.
- seed 1: buffer --seed 1, train --seed 11, in runs_seed1/ and cl_data/buffers_seed1/.
- seed 2: buffer --seed 2, train --seed 12, in runs_seed2/ and cl_data/buffers_seed2/.
- The test keeps eval --seed 0 (the default), so every seed is tested with the same noise as seed 0.
  The only differences between seeds are the buffer selection and the training.
- TMR's selection uses no random numbers, so its PXB184 buffer is the same in all three seeds. Its
  spread comes from training only. GCR, MIR and CSReL also pick a different buffer in each seed.

How to use this file:
- The 8 jobs below do not depend on each other, so each can have its own GPU.
- "buffer" line: run it once. If the buffer file already exists, skip it.
- "train + test" line: if training stops, run this same line again. It continues from the latest checkpoint.
