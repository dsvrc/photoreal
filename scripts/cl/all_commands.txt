PXB184 (step 0, the released model) -> RLW104 (step 1) -> TXB805 (step 2) -> GQS883 (step 3)
Baselines: vanilla er star ocs gcr mir csrel tmr tmr_joint

Run from the repo root in a2p_env:
cd /scratch/ee/staff/kaizer1.cstaff/3d_new/photoreal

How to use this file:
- Each baseline runs its steps in order: step 2 needs that baseline's step 1 model.
  Different baselines do not depend on each other, so each can have its own GPU.
- "buffer" line: run it once, after that baseline's previous step has finished. If the
  buffer file already exists, skip it: a buffer must stay the same in the later steps.
- "train + test" line: if training stops, run this same line again. It continues from the
  latest checkpoint. Do not run the buffer line again for that.
- Replay: every step trains on 32 current + 32 replay windows, with equal weight in the
  loss. The buffers are 10% of each subject's clips and are mixed into one shuffled list.
