COLLECT THE FINE-TUNING vs TMR CONVERSATION VIDEOS (server side)
One script generates the samples (GPU) and packs them. Rendering happens later on the local machine.

Run from the repo root in a2p_env, on a GPU node:
cd /scratch/ee/staff/kaizer1.cstaff/3d_new/photoreal
python scripts/cl/collect_videos.py

Smaller pack (only PXB184 and RLW104, the earlier participants that forgetting hits):
python scripts/cl/collect_videos.py --subjects PXB184 RLW104

If it stops: run the same line again. Checkpoints whose samples exist are skipped.
If checkpoints/ca_body/data is somewhere else, add: --renderer_root /path/to/ca_body/data
Check: the FD_g printed for each checkpoint and subject should match the paper's Tab. a2p cell.

Then copy to the local machine:
cl_data/video_pack.tar.gz
